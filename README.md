# CarrierNote for Claude

Write waste transfer notes in [CarrierNote](https://carriernote.co.uk) from inside Claude. Send a photo of the load, or describe it, and Claude asks only what it can't see, using the customers, sites and vehicles you have already saved in CarrierNote. It checks the note exactly as CarrierNote would, and saves it to your account once you say yes. Signing and anything sent to DEFRA stay in CarrierNote.

## Install

In Claude Code:

```text
/plugin marketplace add carriernote/claude-plugin
/plugin install carriernote@carriernote
```

Then run `/mcp`, choose CarrierNote, and sign in with your CarrierNote account.

You need a CarrierNote account with AI assistants switched on for your business.
